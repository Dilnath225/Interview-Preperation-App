## Common Interview Process in Sri Lankan Companies

### Typical Stages (Most Companies)
1. **Online Application / CV Screening** (1-2 days)
2. **Online Aptitude/Coding Test** (HackerRank, CodeSignal) — 60-90 minutes
3. **Technical Phone Screen** (30-45 min) — Data structures, algorithms, project discussion
4. **Technical Interview (On-site/Virtual)** (1-2 hours) — Coding, system design, project deep dive
5. **Behavioral / HR Interview** (30-45 min) — Culture fit, salary expectations
6. **Final Offer** (1-2 weeks)

### Company-Specific Processes

**WSO2:**
- Strong focus on open-source contributions
- Ballerina language knowledge is a plus
- 2-3 technical rounds including system design
- Values strong fundamentals in distributed systems

**Sysco LABS:**
- Heavy emphasis on coding challenges (LeetCode medium-hard)
- Full-stack knowledge expected (React + Node.js/Java)
- Cloud architecture understanding (AWS)
- Culture fit interview is weighted heavily

**IFS:**
- .NET/C# focused technical rounds
- Enterprise software design patterns
- SQL and database design questions
- Project management methodology awareness (Agile/SAFe)

**99x:**
- Product thinking questions alongside technical
- Focus on clean code and SOLID principles
- Often includes take-home assignments
- Nordic work culture alignment assessment

## Salary Negotiation Tips for Sri Lankan Tech Market

### For Internships
1. **Research the band**: Most SL internships pay LKR 30,000-80,000/month. Top companies (Sysco, IFS) pay higher.
2. **Negotiate through value**: Highlight production-ready skills — "I've deployed a full-stack app with CI/CD"
3. **Ask about conversion**: "What's the path from intern to permanent? What metrics determine conversion?"
4. **Benefits matter**: Transport allowance, meal cards, WFH days, learning budgets can add significant value
5. **Timing**: Best to negotiate after receiving the offer, not during interviews

### For Junior Developers (0-2 years)
1. **Market rate**: LKR 120,000-300,000/month depending on company tier and skills
2. **In-demand skills premium**: React Native, Cloud (AWS/Azure), DevOps, AI/ML → +20-30% premium
3. **Multiple offers leverage**: Having competing offers is the strongest negotiation tool
4. **Don't reveal current salary**: Focus on market value and your skill set
5. **Annual review cycles**: Most companies review salaries every 6-12 months

### Remote/Freelance Rates
- **USD rates**: $15-40/hour for junior, $40-80/hour for mid-level (international clients)
- **Platforms**: Toptal, Upwork, Fiverr (build portfolio first)
- **Sri Lankan advantage**: High English proficiency, time zone overlap with EU/UK, competitive rates

## Interview Communication Tips for Sri Lankan Candidates

1. **English fluency**: Practice technical vocabulary. Record yourself answering questions.
2. **Confidence without arrogance**: Sri Lankan culture values humility, but interviews need assertiveness.
3. **Ask questions**: "What's the tech stack for this team?" shows genuine interest.
4. **Portfolio projects**: Deploy live projects on Vercel/Railway. Active GitHub profile matters.
5. **LinkedIn optimization**: Recruiters in SL actively use LinkedIn. Complete profile, post technical content.
6. **Networking**: Attend tech meetups (Colombo JS, Google Developer Groups SL, Women in Tech SL).
