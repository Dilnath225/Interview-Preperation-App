# Resume & ATS Optimization Guide

## ATS (Applicant Tracking System) Fundamentals

### What is ATS?
- Automated software that scans, parses, and ranks resumes before human reviewers see them
- Used by 90%+ of large companies (including all top Sri Lankan tech firms)
- Filters based on keyword matching, formatting, and relevance scoring
- If your resume doesn't pass ATS, no human will ever read it

### How ATS Scoring Works
1. **Keyword Matching** (40% weight): Exact match of job description keywords
2. **Formatting Compliance** (20% weight): Standard sections, parseable format
3. **Experience Relevance** (25% weight): Role titles, company names, duration
4. **Education & Certifications** (15% weight): Degree, institution, relevant certs

## Resume Formatting Best Practices

### Do's ✅
- Use standard fonts: Arial, Calibri, Roboto, Helvetica (11-12pt body, 14-16pt headers)
- Single column layout for ATS compatibility
- Standard section headers: "Work Experience", "Education", "Technical Skills", "Projects"
- PDF format (unless specifically asked for .docx)
- 1 page for 0-3 years experience, 2 pages max for 3-10 years
- Consistent date format: "Jan 2024 – Present" or "2024 – Present"
- Include links: GitHub, LinkedIn, portfolio (make them clickable)

### Don'ts ❌
- No tables, columns, or text boxes (ATS can't parse them properly)
- No images, icons, or graphics in the main content area
- No headers/footers for important information (some ATS skip them)
- No fancy templates from Canva with complex layouts
- No abbreviations without spelling out first: "CI/CD (Continuous Integration/Continuous Deployment)"
- No personal pronouns ("I built" → "Built")

## The XYZ Resume Formula

### Format
**"Accomplished [X] as measured by [Y], by doing [Z]"**

### Examples
- ❌ Weak: "Worked on the backend API"
- ✅ Strong: "Engineered RESTful API endpoints handling 5K daily requests using Node.js and Express, reducing average response time by 45% through Redis caching implementation"

- ❌ Weak: "Helped improve the database"
- ✅ Strong: "Optimized PostgreSQL query performance by introducing composite indexes and query refactoring, reducing P95 query latency from 800ms to 120ms across 3 critical endpoints"

- ❌ Weak: "Built a mobile app"
- ✅ Strong: "Developed a cross-platform React Native mobile application with 15+ screens, JWT authentication, and offline-first architecture, deployed to 500+ beta users with 4.6★ rating"

## Technical Skills Section Best Practices

### Category-Based Layout (Recommended)
```
Technical Skills
─────────────────────────────────────────────
Languages:        TypeScript, JavaScript, Python, SQL, Java
Frontend:         React, React Native, Next.js, HTML5, CSS3, Tailwind CSS
Backend:          Node.js, Express.js, FastAPI, REST APIs, GraphQL

Tools:            Git, VS Code, Postman, Figma, Jira, Prisma ORM
```

### Keywords That ATS Systems Look For (Software Engineering)
**High Priority**: TypeScript, React, Node.js, Express, PostgreSQL, SQL, Git, REST API, Docker, AWS
**Medium Priority**: CI/CD, Redis, MongoDB, GraphQL, Kubernetes, Microservices, Unit Testing, Agile
**Bonus**: Clean Architecture, SOLID, Design Patterns, TDD, System Design, WebSocket, Kafka

## Resume Template Structure (Optimal Order)

### For Students / Recent Graduates
1. **Contact Information** — Name, Email, Phone, LinkedIn, GitHub, Portfolio
2. **Education** — University, Degree, GPA (if > 3.0), Relevant Coursework
3. **Technical Skills** — Categorized by area
4. **Projects** — 2-3 significant projects with XYZ bullet points
5. **Experience** — Internships, part-time, freelance
6. **Certifications & Awards** — AWS certs, hackathon wins, etc.

### For Working Professionals (1-5 years)
1. **Contact Information**
2. **Professional Summary** — 2-3 sentences highlighting key strengths (optional)
3. **Technical Skills**
4. **Work Experience** — Reverse chronological, 3-5 XYZ bullets per role
5. **Projects** — 1-2 notable side projects
6. **Education**
7. **Certifications**

## Common Resume Mistakes by Sri Lankan Candidates

1. **Including personal details**: Date of birth, NIC number, religion, marital status — REMOVE all of these
2. **Generic objective statement**: "Seeking a challenging position..." — Replace with specific professional summary or remove
3. **Listing every technology ever touched**: Only include technologies you can confidently discuss in an interview
4. **No live project links**: Deploy projects on Vercel, Netlify, or Railway. Include links.
5. **Non-standard file name**: Use "FirstName_LastName_Resume.pdf" format
6. **Inconsistent formatting**: Mixed bullet styles, varying font sizes, inconsistent spacing
7. **No GitHub link**: For software engineers, GitHub activity is as important as the resume itself
